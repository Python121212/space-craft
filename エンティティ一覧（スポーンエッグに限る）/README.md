# エンティティ一覧（スポーンエッグに限る）

`spacecraft` に **スポーンエッグから召喚できるエンティティ**を追加したときに更新する一覧です。
**スポーンエッグを持たないエンティティはここに登録しません**（対象外です）。

**エンティティの見た目はすべて 3D** です。共通の手順・命名規則は [`一覧の使い方.md`](../一覧の使い方.md) にあります。

## 使い方（エンティティを 1 つ追加したら）

1. [`_template.md`](_template.md) を `<id>.md` にコピーします（例 `moon_cow.md`）。
2. `<...>` をすべて埋め、**「使い方」をすべて書きます**。
3. 画像を `images/` に置きます。**すべて 3D モデル由来**:
   - `<id>_egg.svg` … **スポーンエッグの画像**（3D）
   - `<id>_3d.svg` … **その見た目の 3D 画像**（必須）
   - `<id>_egg_held.svg` … **スポーンエッグを持った状態**（3D）
4. md の画像コメントを外して表示されるようにします。
5. 下の表に 1 行追加します。
6. **ビルドは不要**です。この一覧の変更は CI にも jar にも影響しません。

> `ここに追加` はユーザーさんが作ったプレースホルダです。残してください。

## 画像の置き場所

```
エンティティ一覧（スポーンエッグに限る）/
├── README.md          ← このファイル
├── _template.md       ← コピーして使う雛形
├── ここに追加          ← プレースホルダ（残す）
├── <id>.md            ← エンティティごとの説明
└── images/
    ├── <id>_egg.svg
    ├── <id>_3d.svg
    └── <id>_egg_held.svg
```

## 注意

- 実装していないエンティティの md は作らないでください。
- スポーンエッグの入手方法（クリエイティブタブ／レシピ／コマンド）と `/summon` の書式は md の「使い方」に必ず書いてください。
- 見た目の 3D 画像は必ず `models/<id>.json` を元に組み立て、md からリンクしてください。`tools/model3d.py` / `catalog.py render` が使えます。
