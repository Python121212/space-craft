# Ui一覧

`spacecraft` に **UI**（画面・ウィジェット・オーバーレイ・HUD 要素）を追加したときに更新する一覧です。
**UI だけは 2D のまま**です（画面そのものを写すため）。アイテム・ブロック・装備・エンティティはすべて 3D にしてください。
共通の手順・命名規則は [`一覧の使い方.md`](../一覧の使い方.md) にあります。

## 使い方（UI を 1 つ追加したら）

1. [`_template.md`](_template.md) を `<id>.md` にコピーします（例 `fuel_gauge.md`）。
2. `<...>` をすべて埋め、**「使い方」をすべて書きます**。
3. **UI の画像**を `images/<id>_ui.png` に置きます。
4. md の画像コメントを外して表示されるようにします。
5. 下の表に 1 行追加します。
6. **ビルドは不要**です。この一覧の変更は CI にも jar にも影響しません。

> `ここに追加` はユーザーさんが作ったプレースホルダです。残してください。

```
└── images/<id>_ui.png
```

## 画像について

UI は「いうことないが画像を入れる」方針です。**3D 化の対象外**で、該当画面を開いた状態のスクリーンショットを 1 枚置いてください。立体を持たない GUI を無理に 3D にする必要はありません。複数状態（通常／ホバー／無効など）がある場合は `<id>_ui_hover.png` のように接尾辞を付けて追加しても構いません。

## 注意

- 実装していない UI の md は作らないでください。
- 画面の開き方・キー操作・閉じ方は md の「使い方」に必ず書いてください。
