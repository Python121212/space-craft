# アイテム一覧

`spacecraft` に **アイテム**を追加したときに更新する一覧です。
共通の手順・命名規則は [`一覧の使い方.md`](../一覧の使い方.md) にあります。

## 使い方（アイテムを 1 つ追加したら）

1. [`_template.md`](_template.md) を `<id>.md` にコピーします（例 `moon_dust.md`）。
2. `<...>` をすべて埋め、**「使い方」をすべて書きます**。
3. 画像を `images/` に置きます:
   - `<id>_inventory.png` … **インベントリ内の状態**
   - `<id>_held.png` … **手に持った状態**
4. md の画像コメントを外して表示されるようにします。
5. 下の表に 1 行追加します。
6. **ビルドは不要**です。この一覧の変更は CI にも jar にも影響しません。

> `ここに追加` はユーザーさんが作ったプレースホルダです。残してください。

## 登録アイテム

| id | 名前 | md | 状態 |
| --- | --- | --- | --- |
| `wrench` | レンチ | [`wrench.md`](wrench.md) | **実装済み** |

## 画像の置き場所

```
アイテム一覧/
├── README.md          ← このファイル
├── _template.md       ← コピーして使う雛形
├── ここに追加          ← プレースホルダ（残す）
├── <id>.md            ← アイテムごとの説明
└── images/
    ├── <id>_inventory.png
    └── <id>_held.png
```

## 注意

- 実装していないアイテムの md は作らないでください。
- 画像は `gradle runClient` で撮ったゲーム内スクリーンショットに差し替えてください。
- 装備としても使うアイテム（防具・武器・ツール）は [`装備一覧/`](../装備一覧/README.md) にも登録します。
