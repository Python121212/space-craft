# アイテム一覧

`spacecraft` に **アイテム**を追加したときに更新する一覧です。**アイテムはすべて 3D モデルで登録します**。
共通の手順・命名規則は [`一覧の使い方.md`](../一覧の使い方.md) にあります。

## 使い方（アイテムを 1 つ追加したら）

1. [`_template.md`](_template.md) を `<id>.md` にコピーします（例 `moon_dust.md`）。
2. `<...>` をすべて埋め、**「使い方」をすべて書きます**。
3. [`画像/`](../画像/README.md) に置かれた見本 PNG を `itemart.py` の `SOURCE_FILES` に登録し、**テクスチャの source** にします。
4. `models/<id>.json` に **3D の `elements`** を作り、画像を `images/` に置きます。**すべて 3D モデル由来**:
   - `<id>_3d.svg` … **3D モデル全体図**（必須）
   - `<id>_inventory.svg` … **インベントリ内の状態**（3D）
   - `<id>_held.svg` … **手に持った状態**（3D）
   - `python3 tools/itemart.py <id>` でゲーム内モデル・テクスチャ・3 枚の画像を一括生成できます。
5. md の画像コメントを外し、JSON と見本テクスチャへリンクして表示されるようにします。
6. 下の表に 1 行追加します。
7. **ビルドは不要**です。この一覧の変更は CI にも jar にも影響しません。

> `ここに追加` はユーザーさんが作ったプレースホルダです。残してください。

## 画像の置き場所

```
アイテム一覧/
├── README.md          ← このファイル
├── _template.md       ← コピーして使う雛形
├── ここに追加          ← プレースホルダ（残す）
├── <id>.md            ← アイテムごとの説明
├── models/<id>.json   ← 3D モデル（説明用の写し・必須）
└── images/
    ├── <id>_3d.svg
    ├── <id>_inventory.svg
    └── <id>_held.svg
```

## 注意

- 実装していないアイテムの md は作らないでください。
- **2D のスプライト画像は使いません**。3 枚とも `models/<id>.json` の `elements` と実テクスチャの `uv` から組み立てた 3D です。ゲーム内で見た目を確認するときは `gradle runClient` を使ってください（画像の差し替えは不要）。
- 装備としても使うアイテム（防具・武器・ツール）は [`装備一覧/`](../装備一覧/README.md) にも登録します。
